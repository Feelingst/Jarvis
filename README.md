# Jarvis

App base de chat con Claude, lista para desplegar en Vercel.

## Pasos para publicar

1. Sube esta carpeta a un repositorio nuevo en GitHub (ver guía en el chat).
2. En Vercel, "Add New Project" → importa ese repositorio.
3. En "Environment Variables" añade:
   - `ANTHROPIC_API_KEY` = tu clave de https://console.anthropic.com
4. Despliega. Vercel te dará una URL como `https://jarvis-tuusuario.vercel.app`.
5. Abre esa URL en Safari (iPhone) → botón compartir → "Añadir a pantalla de inicio".
6. En PC, abre la misma URL en cualquier navegador.
